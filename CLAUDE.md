# cve.now

The GitHub home of [cve.now](https://cve.now), a free, public vulnerability feed: docs and issue forms, no source code. Usage docs are in `README.md`.

## About

This repository mirrors files from the private Sazabi monorepo (`apps/cve-now/public-repo/`). They sync here on every merge to `main`; there are no releases. Do not commit directly or open pull requests: direct changes are overwritten on the next sync. Edit the files in the monorepo instead.

## Issues & support

File issues here or email [support@sazabi.ai](mailto:support@sazabi.ai). Report security problems in cve.now itself to [security@sazabi.ai](mailto:security@sazabi.ai), never in a public issue.
